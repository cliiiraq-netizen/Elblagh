# مرجع تجربة صفحة الطلب في «اوصلي» (ewsali.com) — للتصميم بهوية إبلاغ

تاريخ الفحص: 2026-11-26 · متصفح Chromium (iPhone 13 + 1440px) · **كل طلبات الإرسال (POST) كانت محجوبة، وزر «تأكيد الطلب» ما انضغط بعد تعبئة البيانات — ما انرسل أي طلب.**
التقنية عندهم: Next.js + React + Tailwind، خط Thmanyah Sans، صوت التنبيه مولّد بـ WebAudio (12 نبضة).

## صفحات الموقع (9)
الرئيسية `/` · الطلب `/order` (= `/pricing`) · بتشتغل إزاي `/how-it-works` · تواصل `/contact` · دخول `/login` · نسيت الباسورد · الخصوصية · الشروط · سياسة التواصل. قائمة الهامبرغر: إزاي بيشتغل، الأسعار، اطلب أونلاين، تسجيل الدخول.

## صفحة الطلب — من فوق لتحت
1. **هيدر:** شعار يمين، «🔒 إتمام الطلب» يسار.
2. **هيرو** (خلفية فاتحة دافئة + 3 بقع لون تتحرك 18/22/26 ث + حبيبات + شبكة نقاط):
   - عنوان سطرين: أسود ثم رمادي، وسطر ثالث ملوّن صغير — كل سطر «يصعد» (rise 0.8 ث) بالتتابع.
   - زر صوت دائري (اكتم/شغل الصوت؛ الأيقونة تتغير لـ ×).
   - **تسلسل تلقائي عند الفتح:** 0.8 ث ينزل إشعار واتساب فوق الملصق → 1.2 ث كبسولة سوداء «اتصال وارد» بزر أخضر ينبض، والملصق ينزاح لتحت (padding 0.65 ث) → 1.6–2 ث يختفون ويرجع الملصق → 2.8 ث يظهر مفتاح فاتح/غامق.
   - **الملصق زر** («جرب: دوس على الستيكر وشوف التنبيه اللي بيوصل»): يعيد التسلسل + النغمة (إلا إذا مكتوم). الملصق يطفو (5 ث)، ظله يتنفس، لمعة تمر عليه (6.5 ث)، حلقات دائرية حوله، سقوط أولي (1.1 ث).
   - مفتاح **فاتح / غامق** يبدّل صورة الملصق بحركة swap 0.42 ث.
   - زر «اطلب من هنا ⌄» بتوهج وسهم يتحرك، ينزل للطلب (تمرير ناعم). عند النزول يصير عائم أعلى الشاشة.
3. **الخطوات:** دائرتين (1 الباقة — 2 التوصيل والدفع) بينهم خط؛ الخطوة المنجزة ✓ رمادي-أخضر، الحالية ملوّنة. قابلة للضغط. الانتقال بحركة انزلاق (للأمام/للخلف).
4. **«اختار باقتك»** — بطاقتين (radio): أيقونة، اسم الباقة، وصف، السعر كبير «/ سنة» + «يعني X في الشهر»، 3 مزايا بأيقونات، زر «اختار الباقة دي» → بعد الاختيار يصير «✓ تم اختيار الباقة» معبّى والبطاقة إطارها ملوّن.
5. رابط «▶ شوف بتشتغل إزاي، خطوة بخطوة» → **نافذة سفلية (bottom sheet)**: تبويبين للباقتين + خط زمني متحرك (story-in): 0:00 حد عمل سكان (شرائح المشكلة) · 0:01 يوصلك واتساب (إشعار) · 2:00 متشافش؟ هنرنلك (كبسولة الاتصال) · ✓ ضغطة واحدة «جاي حالاً» · (بلس) رقم ثاني + SOS لـ 3 من الأهل.
6. **«اختار ستيكراتك»** + شارة العدد («ستيكر واحد»/«ستيكرين»): بطاقة لكل تصميم (فاتح/غامق) بصورة + عداد − رقم +؛ شارة «1×» على البطاقة المختارة (pop). أقصى 8 لكل تصميم، الحد الأدنى الكلي 1 (يتعطل −).
7. بطاقتي ضمان: «ستيكر جديد مع التجديد»، «ضمان استبدال لعيوب التصنيع».
8. «عندك سؤال؟ كلمنا واتساب».
9. **شريط سفلي ثابت:** «المجموع / إجمالي الحساب» + الرقم (يرمش 0.28 ث عند التغيير) + الزر: «اختار باقتك» (قبل الاختيار) → «كمل طلبك ←» → في الخطوة 2: «رجوع» + «🔒 تأكيد الطلب».

## الخطوة 2 — التوصيل والدفع
- سطر: «الدفع عند الاستلام · التوصيل من 2 لـ 5 أيام».
- **بيانات التواصل:** الاسم بالكامل (autocomplete=name) · رقم الهاتف مع بادئة الدولة، أرقام فقط (يحذف الحروف)، تلميح تحت الحقل.
- **عنوان التوصيل:** المحافظة (قائمة) + المدينة أو المنطقة (**تعتمد على المحافظة**) + العنوان بالتفصيل.
- **سعر التوصيل حسب المحافظة** (75 → 145).
- **بطاقة إضافة (upsell)** تظهر بعد اختيار المحافظة إذا الطلب ملصق واحد: «توصيل مجاني — زود ستيكر كمان ووفر التوصيل — التوصيل X — خليه لعربية تانية أو اديه لحد يهمك — [+ زود ستيكر]». بعد الضغط: «طلبك دلوقتي بتوصيل مجاني 🎉 — التوصيل ~~X~~ مجاناً — ✓ تمت الإضافة». القاعدة: ملصقين أو أكثر = توصيل مجاني.
- **طريقة الدفع:** «عندك كود خصم؟» (يفتح حقل + «تطبيق»، التحقق من السيرفر) · بطاقتين: الدفع عند الاستلام / إنستاباي → يفتح صندوق: المبلغ المطلوب، معرّف التحويل + «نسخ»، «افتح تطبيق إنستاباي»، «ارفع صورة التحويل» (رفع ملف)، «طلبك هيتأكد بعد مراجعة التحويل».
- **ملخص (بطاقة صفراء فاتحة):** صورة ملصق، «الباقة × العدد»، التوصيل (أو «اختار المحافظة»)، الإجمالي. تحته «🔒 دفع سهل وآمن».
- **التحقق عند الضغط بدون بيانات:** رسائل تحت كل حقل + إطار أحمر: «اكتب اسمك الكامل.» «اكتب رقم موبايل … صحيح» «اختار المحافظة.» «اكتب الشارع ورقم العمارة.»
- **الرجوع** للخطوة 1 يحفظ كل البيانات المكتوبة.
- شاشة النجاح/الإيصال لم تُرَ (تحتاج طلب حقيقي). أسماء الحركات بالكود تدل على: ظهور إيصال + ملصق + علامة صح.
