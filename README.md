# إبلاغ — العرض التجريبي الكامل

نسخة كاملة ومستقلة من ديمو **إبلاغ** في ملف واحد `index.html` (لا يحتاج سيرفر أو تثبيت).

## التشغيل
- افتح `index.html` مباشرة بالمتصفح، أو
- `python3 -m http.server 8000` ثم افتح http://localhost:8000

## الواجهات (8)
1. **التدفق المباشر** — المُبلِّغ وصاحب السيارة جنباً إلى جنب مع سجل الأحداث.
2. **المُبلِّغ (متصفح)** — الكاميرا ← صفحة الهبوط ← كتابة البلاغ ← حالة البلاغ ← ملصق غير مفعّل.
3. **تطبيق صاحب السيارة** — الرئيسية، البلاغات، تفاصيل البلاغ والرد، سياراتي، إضافة ملصق، الإعدادات.
4. **تسجيل زبون جديد** — البداية، الدخول، رمز التحقق، الملف الشخصي، الباقات، التوصيل، الدفع، التأكيد.
5. **الحجز المسبق** — صفحة اختبار السوق: عدّاد أول 100، اختيار الباقة، حجز بدون دفع، رابط إحالة.
6. **الشركات والمجمعات** — باقات الأساطيل والمجمعات والجامعات، طلب عرض سعر، ولوحة الشركة/المجمع.
7. **الملصقات** — تصاميم الملصقات مع وضع القص، وكرت التفعيل يحمل الرمز السري.
8. **الإدارة** — نظرة عامة، الدفعات مع تتبّع المراحل، الطلبات، البلاغات، وصول الإشعارات، الإساءات، المستخدمون، الإعدادات.

## الإضافات الأخيرة
- تفعيل الملصق بالمسح أو بالرمز السري (مع قفل بعد 5 محاولات خاطئة).
- حالات الخطأ: ملصق غير مفعّل، رمز غير صالح، بدون إنترنت، وصل الحد، فشل الدفع.
- ملاحظة صاحب السيارة تظهر بصفحة المسح (مثل «راجع خلال 10 دقائق») مع مدة انتهاء.
- كود الإحالة بالحساب والتسجيل مع خصم بملخص الدفع.
- صفحة المسح كإعلان: سطر أسفل الصفحة، إعلان وقت الانتظار، وعرض بكود SCAN-2K بعد الحل.
- إدارة الطلبات مربوطة بتطبيق الزبون، ونسبة وصول الإشعارات حسب القناة.

يدعم: العربية / English / کوردی، الوضع الداكن والفاتح، اختيار الخطوط، وزر إعادة العرض من البداية.
